# Generative Agents and Social Simulation

## Why this bucket matters

This bucket anchors Loomstead against believable social simulation. The key distinction to preserve: prior work focuses on believable autonomous behavior in a simulated society; Loomstead focuses on goal-conditioned orchestration where a Director changes world conditions and then evaluates whether the resulting process stayed credible.

## Selected sources

| Source | What to cite | Contrast for Loomstead |
| --- | --- | --- |
| Park et al., 2023, *Generative Agents: Interactive Simulacra of Human Behavior* | Memory stream, reflection, planning, and a small-town sandbox that produces believable emergent social behavior. | Loomstead should credit the believable-agent architecture and then emphasize process-constrained goals, allowed interventions, hard-delegation baselines, and Process Fidelity metrics. |
| Vezhnevets et al., 2023, *Concordia* | Generative agent-based modeling with grounded physical / social / digital environments and a Game Master that translates natural-language actions into environment effects. | Compare Concordia's Game Master environment mediation with Loomstead's Director / Event Skill / ToolExecutor split and schema-backed trace export. |

## Notes to turn into prose

- Use Generative Agents as the closest human-behavior simulation reference.
- Use Concordia as the broader generative agent-based modeling environment reference.
- Avoid claiming memory, reflection, or small-town agents as novel by themselves.
- Novelty should be framed around motivational delegation and process-fidelity evaluation for user goals that cannot be reduced to final state changes.
