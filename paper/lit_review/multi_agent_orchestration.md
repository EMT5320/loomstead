# Multi-Agent Orchestration

## Why this bucket matters

This bucket anchors the contrast with explicit task delegation, role-based workflows, and conversation-driven worker agents. Loomstead should present Hard Delegation as the baseline family represented by these systems, while being careful that these systems solve different task-oriented problems.

## Selected sources

| Source | What to cite | Contrast for Loomstead |
| --- | --- | --- |
| AutoGen | Customizable conversable agents, human / tool / LLM operation modes, and multi-agent conversation patterns for LLM applications. | Strong baseline for conversation-based orchestration; Loomstead differs by using indirect interventions and process constraints in a persistent social world. |
| MetaGPT | Encodes SOPs into prompt sequences and decomposes software work into role-based assembly-line collaboration. | Strong contrast for explicit workflow decomposition; maps to static todo / hard delegation baselines. |
| ChatDev | Specialized software agents communicate through a chat chain and communicative dehallucination for design, coding, and testing. | Useful secondary-domain comparison for coding fixtures and task-oriented multi-agent societies. |

## Notes to turn into prose

- These systems are valuable references for task-secondary validation.
- Loomstead should avoid claiming to beat them on software tasks.
- The paper should instead argue that narrative process goals expose failure modes of direct assignment: forced action, shortcut state edits, and missing social side effects.
